# Why this folder is still here

JSONL Vision 0.3.0 is already published to the VS Code Marketplace and Open VSX.
That listing's README embeds this exact URL:

`https://raw.githubusercontent.com/cyclone-mind/jsonl-vision/main/jsoncrack.com/apps/vscode/assets/demo.gif`

A published README cannot change until the next release, and this restructure does
not bump the version. `demo.gif` stays at this path so the live listing image
does not 404.

The extension now lives at the repository root. The current README points at
`assets/demo.gif`.
